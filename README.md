# README 
## Python: 
- python/scheduler.py is the console app and scheduling logic. python/scheduler_gui.py is the optional Tkinter GUI for entering employees and viewing the schedule.
## C#: 
- csharp/Program.cs and ShiftScheduler.csproj make up a .NET 8 console app with the same logic.
## Screenshots: 
The PNGs are in screenshots/ (Python and C# schedule output, plus the two GUI tabs).
##To run them: 
`python scheduler.py --demo --seed 7 for Python, or dotnet run -- --demo --seed 7 for C#.`
